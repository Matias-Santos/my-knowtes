# React Native: Platform Overview

React Native is a development platform that generates native components suited to each target platform. Rather than rendering to a web DOM, it maps React components to their native counterparts — for example, a `<View>` becomes a native UIView on iOS or an Android View on Android.

## Insight

Understanding that React Native outputs truly native components (not web views) is foundational — it explains both its performance characteristics and why platform-specific behavior sometimes needs to be handled explicitly.
