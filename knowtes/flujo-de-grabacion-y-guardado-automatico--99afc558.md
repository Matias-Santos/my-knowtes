# Flujo de Grabación y Guardado Automático

El flujo descripto indica que una vez que se finaliza una grabación, toda la información capturada se almacena de forma automática. El proceso es continuo: a medida que se graba, los datos se van acumulando, y al presionar para detener o confirmar, quedan guardados en el sistema sin pasos adicionales.

## Insight

Un guardado automático al finalizar la grabación elimina fricción y reduce el riesgo de pérdida de datos. Confirmar que este comportamiento es consistente y confiable es clave para que los usuarios confíen en el sistema y adopten el hábito de grabar sin preocuparse por guardar manualmente.
