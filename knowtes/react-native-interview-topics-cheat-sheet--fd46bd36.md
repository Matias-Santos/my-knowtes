# React Native Interview Topics Cheat Sheet

## Core Topics to Cover

- **Components & JSX** — Functional vs class components, props, and composition
- **State Management** — `useState`, `useReducer`, and external solutions (Redux, Zustand)
- **Navigation** — React Navigation: stack, tab, and drawer navigators
- **Lists & Performance** — `FlatList` vs `ScrollView`, lazy rendering, `keyExtractor`
- **Styling** — `StyleSheet.create`, Flexbox layout, platform-specific styles
- **Networking** — `fetch` / `axios`, loading states, error handling
- **Native Modules** — Bridging JavaScript to native iOS/Android code
- **Hooks** — `useEffect`, `useCallback`, `useMemo`, custom hooks
- **Platform APIs** — `Platform.OS`, permissions, camera, location
- **Testing** — Jest, React Native Testing Library
- **Build & Deployment** — Expo vs bare workflow, app signing, OTA updates

## Insight

Prioritize `FlatList`, `useState`, and navigation since these appear most frequently in React Native technical screens — review the linked Knowtes on those topics first.
