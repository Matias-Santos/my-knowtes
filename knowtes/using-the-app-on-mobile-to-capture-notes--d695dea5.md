# Using the App on Mobile to Capture Notes

The application is now fully usable from a personal phone via the notes webpage. This means notes can be captured directly from a mobile browser, enabling on-the-go voice note recording without needing a separate device or desktop setup.

## Insight

Mobile accessibility is a critical milestone — it removes friction from the capture process. When note-taking works seamlessly on the device people already carry, they're far more likely to use it consistently and in the moment ideas actually occur.
